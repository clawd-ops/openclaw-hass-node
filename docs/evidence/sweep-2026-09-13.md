### FAIL -- gateway/node command-name mismatch

Gateway `dir_list` and `file_fetch` MCP tools call `dir.list` / `file.fetch`, but the
hass linux-family node advertises `fs.list` / `fs.read`. Filesystem reads never reach
hass despite `fs.*` shipping. Fix: gateway alias map for linux nodes, or node-side
aliases. Tracked in GitHub issue.
